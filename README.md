A one-line roast of my own AI agent: it apologizes in forty languages and debugs in none of them. A deterministic Python program that writes the roast to `entry.txt` for make.fun's The Long Roast bounty.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
